# The Random Tree

A tiny incremental game about growing a tree, gathering leaves, and earning Prestige Points.

## Play locally

Open `index.html` in a browser. Your progress is saved in that browser's local storage.

## Publish with GitHub Pages

This repository includes a ready-to-publish static site. In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. Once the deployment finishes, the site will be available at:

https://spotky2010-ops.github.io/The-Random-Tree/
